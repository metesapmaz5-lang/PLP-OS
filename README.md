
# PLP-OS (Parabellum Linux Project) - v1.0 "Tyr"

PLP-OS is a pure, minimalist, and performance-oriented GNU/Linux distribution based on **Debian 13 (Trixie)**. Stripped down to the absolute essentials, it offers total control over your system without any bloatware or invasive telemetry.

> *"Si vis pacem, para bellum."*

## Features
* **Base:** Debian 13 (Trixie) - Stable and modern core.
* **Init System:** `systemd` (Fully optimized and cleaned from unnecessary services).
* **Bloat-Free:** Only the core packages are installed. You decide what goes into your system.
* **Performance:** Extremely low resource usage and fast boot times.

## Future Roadmap (v2.0)
* Migration from `systemd` to `OpenRC` for true init-system independence.
* Advanced custom post-install scripts.

## Installation
Currently, PLP-OS does not include a GUI installer. It is designed for users who are comfortable with the terminal. 

1. Download the latest ISO from the Releases section.
2. Flash it to a USB drive.
3. Boot and follow the minimal CLI setup.
